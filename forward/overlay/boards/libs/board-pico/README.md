# Raspberry Pi Pico

Board package for the Raspberry Pi Pico (RP2040). Projects that depend on it compile with the
`fwdpico` variant: the micro:bit blocks, built against Forward's CODAL layer
(`Forward-Education/codal-forward-brain`) into a `.uf2` for the Pico's RPI-RP2 drive.

Device switcher phase 1 (`forward/docs/device-switcher.md`). Only in builds with `FWD_BOARDS=1`.
